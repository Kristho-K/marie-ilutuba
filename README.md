# Marie ilutuba – 9. seminar

Ülesanne 1: kaks Git-haru muutsid faili `conflict.md` ühte ja sama rida. Harude ühendamisel tekitati ja lahendati merge-konflikt.

Ülesanne 2: loodud on Marie ilutoa näidisveebileht. Avalehel on galeriipilt, sotsiaalmeediaikoonid, asukohakaart, näidisaadress ja lahtiolekuajad. Lisaks on hinnakirja näidisleht ja broneerimise ooteleht.

## Veebilehe avamine

Ava fail `index.html` veebibrauseris või kasuta VS Code'i Live Serveri laiendust. Hinnakirja ja broneerimise lehtedele pääseb avalehe menüü kaudu.

## Oluline

Asukoht, lahtiolekuajad ja hinnad on õppeülesande jaoks **näidisandmed**, mitte päris ilutoa andmed. Galeriipilt ja Google Mapsi kaart vajavad internetiühendust. Instagrami ja Facebooki ikoonid on kliendi soovi järgi esialgu näidisikoonid; Tumblr viitab näidiskontole. Päris broneerimissüsteemi ei ole.
